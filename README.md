# educ_srh

This code accompanies the article: Lariscy, Joseph T., and Israt Jahan. (2025). [Sex-specific trends in educational attainment and self-rated health, 1972-2018](https://www.tandfonline.com/doi/full/10.1080/19485565.2024.2448941). *Biodemography and Social Biology* 70(1): 57-64.

The data are imported from the R package [gssr](https://kjhealy.github.io/gssr/) developed by Kieran Healy. Thus, no data file is included in the git repository.
