# educ_srh

This code accompanies the article "[Sex-Specific Trends in Educational Attainment and Self-Rated Health, 1972-2018](https://www.tandfonline.com/doi/full/10.1080/19485565.2024.2448941)," published in *Biodemography and Social Biology* 70(1): 57-64.

The data are imported from the R package [gssr](https://kjhealy.github.io/gssr/) developed by Kieran Healy. Thus, no data file is included in the git repository.
